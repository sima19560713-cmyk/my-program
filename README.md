# こだぬきⅡ

「こだぬきⅡ」は、将棋AI「お袖狸」を土台に、TataraによるNNUE評価関数の追加学習と、直接対局での検証を重ねて開発している将棋AIです。

開発者名は「こだぬき」です。まだ強豪には歯が立ちませんが、一歩ずつ挑戦を続けます。

## 特徴

- やねうら王系の探索エンジンとNNUE評価関数を使用しています。
- 開発では、Ryfamateの評価や実際の棋譜の勝敗などを学習に活用してきました。
- 改良候補は基準版との直接対局で検証し、学習の完了や検証値の改善だけで「強くなった」とは判断しません。
- 公開名は「こだぬきⅡ」です。「快速策」は、今回の配布対象となる版の開発上の名称です。

## 開発と対局について

Claude・Codex・Geminiを、調査、改良案、コード作成、結果の分析などの開発補助に利用しています。人間が実行結果を確認し、最終判断を行います。

対局中は人間や対話型AIが指し手を選ぶのではなく、将棋エンジンが自動で指します。

## 無料配布について

Windows AVX2版の実行ファイルと評価関数を、無料配布するために準備しています。公開後は、このリポジトリの[Releases（配布ページ）](https://github.com/sima19560713-cmyk/my-program/releases)からダウンロードできます。

- 対象環境：Windows 64bit、AVX2・BMI/BMI2対応CPU、ShogiHomeなどのUSI対応GUI。GPUは不要です。
- 同梱予定：実行ファイル、評価関数、進行度ファイル、設定、使い方、権利表示。探索プログラムのソース資料は別ZIPで案内します。
- 定跡は同梱しません。配布設定は定跡OFFです。教師モデルや学習データも同梱しません。
- 大会で使用した快速策の評価関数を収録するWindows版です。大会時のAWS/Linux実行ファイルそのものではありません。

評価関数・進行度ファイルの読み込みとUSIの準備完了応答を確認しています。2026年11月17日、公開ZIPを別フォルダに展開し、ShogiHome 1.29.1で配布版どうしの1局対局を確認しました。101手まで進み、投了で正常に終局しました。

無料配布と、無条件の再配布・改変許可は別です。各構成物の利用条件は、配布物に同梱するライセンス・権利表示をご確認ください。

## 使用技術・謝辞

- **やねうら王・お袖狸（tanuki-）**：探索エンジン、USI通信、NNUE評価の基盤。
- **Tatara**：NNUE評価関数の学習・書き出し。
- **Ryfamate Cross Network**：学習用教師モデル。使用モデル：`ryfc20b_ep06_095.tsec4`。作者：駒の書体（Komafont）氏。
- **cshogi・ONNX Runtime**：学習・検証時の局面処理、教師モデルの推論。

開発を支えるソフトウェア、モデル、データの作者の皆様と、大会運営・対局相手の皆様に感謝いたします。
