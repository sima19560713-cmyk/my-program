# my-program# こだぬきⅡ

「こだぬきⅡ」は、将棋AI「お袖狸」を土台に、評価関数の追加学習と実測による検証を重ねて開発している将棋AIです。

## 特徴

- やねうら王系の探索エンジンと、NNUE評価関数を使用しています。
- Tataraを用いて評価関数を追加学習しています。
- 開発では、Ryfamateの評価や棋譜の勝敗などを学習に活用してきました。
- 改良候補は、基準となる版との直接対局で確かめています。学習が完了しただけで、強くなったとは判断しません。

## 開発について

開発者は、「こだぬき」です。

Claude・Codex・Geminiを開発の補助に利用しています。
AIから改良案やコード作成の支援を受け、人間が実行結果を確認し、最終判断を行います。

対局中は人間や対話型AIが指し手を選ぶのではなく、将棋エンジンが自動で指します。

## 大会参加
